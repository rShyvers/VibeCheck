Tic-tac-toe on the verified machine

You play X. Each time you click a cell, this page sends one MIPS program to the interpreter. That program checks your move, makes the computer's reply, and reports a win or a draw. The page has no game rules of its own: it only shows the board the program prints.

X = you · O = computer
Total MIPS instructions executed this game:0

The opponent takes a win or a block when available, but has no fork detection — a careful player can beat it. Every move, win, block and draw you see was checked by the real MIPS interpreter, not hardcoded.

What is checked and what is tested: the MIPS semantics this runs on (step/decode) passes kernel-checked verification gates against its own written spec and is differentially validated against real MARS 4.5 (see the Verdict tab). This game program itself has no such proof — it was tested exhaustively instead: all 34,529 board/move combinations and 775 full games, with no failures.
